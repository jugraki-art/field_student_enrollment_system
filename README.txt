Kinondoni Municipal Council HQ - Field Student Enrollment System
------------------------------------------------------------------

Included Files:
1. index.html - Modern responsive UI form & data table.
2. style.css - CSS styling matching municipal portal standards.
3. app.js - Client-side business logic, localStorage, CSV export, date validation.
4. schema.sql - MySQL database table definition.
5. api.php - PHP backend for XAMPP LAN deployment.

Deployment Instructions:
- Standalone Mode: Simply double-click `index.html` in any web browser. Data persists in browser storage.
- LAN / Server Mode: Copy all files to `htdocs/pt_system/` in XAMPP. Import `schema.sql` into MySQL.
